# Homepage font subsets

The homepage serves local WOFF2 subsets of Noto Sans Arabic and Manrope from Google Fonts. Each family includes regular (400) and bold (700) instances. The included SIL Open Font License files apply to the respective families.

The Arabic subsets include characters used in the homepage and its bundled Arabic UI strings, with shaping tables retained. Refresh the subsets when adding new Arabic characters. Manrope also supplies the homepage's DM Sans fallback alias so the first render does not request a third font family.

Sources: https://fonts.google.com/noto/specimen/Noto+Sans+Arabic and https://fonts.google.com/specimen/Manrope.
